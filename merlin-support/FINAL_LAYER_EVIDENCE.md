Final compiler-pass layer evidence
=================================

The original final functional/certification gate remains mandatory. The layer
consumer additionally reopens the current compiler and its original source
snapshot, complete L2 outputs, selected Fire-aligned runtime and executed-program
V2 artifacts. It independently traces both original ELFs and checks decoded
commands, complete typed outputs and logical transfer windows before invoking
the source-pinned live mechanism owner. Native model evaluation uses the same
bounded issued-program helper.

V2 compiler-artifact retention and this consumer do not certify a provisional
Phase 1 compiler, enable an unqualified mechanism or supply timing authority.
Missing original grading, source, command buffer, LLVM, kernel, complete console,
build or completed invocation evidence refuses additional pass realization.

Verification:

    python -m pytest -q merlin-support/tests/test_cleanup_layer_artifacts.py \
      merlin-support/tests/test_cleanup_final_guard.py \
      merlin-support/tests/test_compiler_pass_preparation.py

These focused tests include synthetic evidence and refusal controls. Fresh
functional Spike traces establish issued programs and values only; accelerator
cycle claims require the independently selected, calibrated timing domain.
