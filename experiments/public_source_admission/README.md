# Original public source admission

This operator-only experiment connects existing Phase0 owners for an already
sealed public integer source. It does not run compiler authors or performance
search, qualify timing, change a numerical recipe, or replace the original
Phase1 package. The complete retained 243-member/90-requirement plan is reopened;
one declared member is selected without changing its role or dropping refusals.

Run from an existing managed task with Merlin's experiment package, the selected
OOT backend support and the declared compiler Python on `PATH`:

```sh
python experiments/public_source_admission/admit_sources.py \
  --declaration /absolute/operator-declaration.json --sha256 "$DECLARATION_SHA256" \
  --output /absolute/fresh-check-output --check-inputs
```

`--check-inputs` reopens the original complete plan, compiler inventory, source,
full independent inputs/outputs, sealed capture and operator role/private
selection. It executes no compiler or target and grants no admission. The
original private eligibility check needs the materialized capsule and runs at
the beginning of `--execute`, before expensive compilation/native execution.

`--execute` must run under the existing external process-tree resource
supervisor, using a predeclared immutable purpose with a finite deadline. This
CLI does not create, prove or claim that external CPU/RSS/disk boundary. Select
common `MERLIN_COMPUTE_CPUS`/`MERLIN_COMPUTE_CPU_SLOTS`, thread count one, task-owned
`TMPDIR`, and the already reviewed native toolchain/runtime environment. The
original compiler45s/native60s/trace60s limits and64MiB trace file ceiling remain.
The declared purpose may select at most120 aggregate CPU seconds,300wall,
1GiB RSS and128MiB new output. Actual supervision, cost and cleanup receipts
remain external inputs to any subsequent readiness claim.

The emitted ABI chooses the original execution route. A real `whole_program`
uses the original model executor and source owner. A standalone pointer ABI
uses the explicitly versioned pointer executor and strict direct source owner.
Neither route manufactures a global plan or changes the emitted command buffer.
Unsupported operations, bindings and complete-effect proofs refuse normally.
For example, the retained half-up source remains refused when the unchanged
compiler cannot lower its `arith.floordivsi`.

The operator declaration has the closed schema
`gemmini.public_source_admission.v1` and these fields:

- `readiness`, `job_plan`: exact `{path,sha256}` pins for the original readiness
  and `merlin.phase0.development_admission_job_plan.v1`. Re-derivation must equal
  the complete original plan; it is never an execution permit.
- `source`: `identity`, `ordinal`, `manifest` pin, original sealed `attestation`
  pin, exact `program` and relative `source_member`, selected `supplements` pins,
  `input_binding`, and the existing capture-intake `cost_limits` dictionary.
  Original full NPZ references use `input_binding: null`. Supplemental raw
  rank2 sources select `{native_result: PIN}` only to reopen historical input
  bytes and their original loader; original seed ownership is rechecked. This
  grants no historical execution or numerical verdict.
- `roles`: original `profile` and `private_exclusion` pins. Both original live
  selectors are required; a caller's role label or saved success is ignored.
- `compiler`: canonical `root`, original complete `inventory` pin, complete
  sorted-path/NUL/bytes/NUL `sha256`, and `python`. The latter contains the exact
  `launcher` resolved by the manifest's `python3`, actual `binary` pin, and
  `venv_config` pin. No environment is copied or installed.
- `factory_inputs`: pin to the original generated-source factory inputs;
  `execution_contract`: the exact canonical runtime-selected contract pin.
  ABI selection only supplies the existing original binding protocol fields.
  It selects no arbitrary callback, shell or serialized grant.
- `purpose`: original finite per-member purpose pin with `start_utc`,
  `deadline_utc`, `identity` and `limits` as listed above.

Pins may include exact `bytes`. All metadata reads are bounded, selected inputs
are reopened after verification, and output roots must be fresh and outside the
immutable source/capture/compiler trees. The source and complete references
remain byte-identical. The copied diagnostic view changes only required ISA
classes and requested L0–L3 tiers; original qualification/exclusion gates remain.
The final writer executes under the original live role, realization and private
selection owners. A partial or failed write is rolled back by ordinary staging.

The operator output is private setup/verification evidence. Only an actually
published capsule is a public writer result. Neither that result nor this CLI
establishes formal full-cohort or hardware/timing qualification. Guard/objective
membership and historical refusals remain in the complete original plan.

An operator may explicitly select
`source_binding_protocol: gemmini.pointer_source_contractions.v1` in a **new**
`factory_inputs` release. This separate source checker accepts multiple
zero-initialized signed-i8/i32 rank-two contractions with immutable function
inputs and complete distinct returned outputs. The source return order must
match the actual positional pointer ABI, including each shape and type. It
does not infer ownership from compiler tensor-name suffixes, fabricate a global
plan, or accept casts, packed operands, unreturned computations or intermediate
arithmetic. The existing single-dot protocol remains the default.

The new owner reuses the complete native/source/reference checks and original
packet engine for every contraction, and checks CPU writes to **every** returned
output during the original call. Its source closure is frozen before factory
restoration; constructor type/protocol, callbacks and artifact identities are
revalidated. A new source release and fresh execution evidence are required;
old refusals and owners are never repinned or upgraded. This interface does not
qualify scheduling capabilities, hardware execution or timing, and does not
change the compiler package or the selected numerical policy.
