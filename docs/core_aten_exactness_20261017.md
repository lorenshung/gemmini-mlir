# Core ATen exactness qualification, 2026-10-17

The reference backend uses exact rational arithmetic on integer codes and the **actual source scale values**, followed by round-half-to-even and the declared clamp. Eager floating Q/DQ is informational. Existing historical model accuracy gates and captured fixture bytes are unchanged.

## Changes

- **1:** Symbolic affine coefficients and reduction divisors retain rational values. Admission checks every monotone hardware output transition over the whole bounded accumulator interval, including the i32-to-f32 conversion. Affine weight candidates are exhaustively checked over all 256 or 65,536 byte inputs. Integer partial sums must fit SRAM. Constant quantization uses exact division and RNE. No error tolerance grants admission.
- **3:** C-interface descriptor offsets advance typed pointers in elements. A compiled native regression covers nonzero int32 bias and output offsets, result descriptors, and guards around both buffers.
- **5 (target side):** The source-bound region catalog recognizes seeded integer MACs and their closed int8 readout. It checks legacy RNE bodies structurally, and delegates canonical exact integer readout-body regeneration to the installed model2MLIR source owner rather than copying that algorithm. Constant seeds are bounded from their current IR values. Runtime seeds require a checked, retained source range assertion. The provider supplies source-operation ordinals, numerical schedule proofs, and the region ABI; both emitted objects and final e2e ELFs are audited for forbidden instructions.
- **9 (target side):** `merlin-support/tools/sync_contracts.py` regenerates target/residual contracts from the selected Merlin contracts, adapting only provider plugin declarations. `--check` and the drift test compare generated bytes and parsed semantics. The generated migration receipt extends, rather than edits, historical provenance receipts.
- **3, follow-up:** Dense kernel argument descriptors now retain the actual source view ranks. A flattened matmul readout regression verifies rank-1 output descriptors and exact output codes.
- **11:** Empty/dynamic shapes and invalid reduction dimensions decline before division, indexing or stream emission.
- **12:** Both small and representative extension suites generate the odd-size ceil/divisor case. It lowers and is checked against an independent rational window oracle.
- **13:** The capture helper imports the selected installed `m2m`; it has no absolute checkout injection.

The old randomized transposed-convolution geometry matcher and floating coefficient-to-integer weight approximation are removed from admission. Those regions remain host work until their symbolic maps, intermediate bounds and readout can be proved.

## Cross-repository integration boundary

The target returns the existing `DeviceRouting.region_offload` ABI for a closed seeded MAC/readout region. As inspected during qualification, Merlin's `routing_for_bundle` contraction branch still requires `catalog_builder` or `exact_selection` and rejects a region-only route with `batch device mode requires source-bound catalog or exact selection`. Merlin must admit the region ABI at that reusable dispatch boundary. The target's source catalog, provider routing/proof unit tests and direct/whole-model Spike and RTL paths are qualified independently. No Merlin files were edited here.

## Refusal policy

The current device ABI supports signed per-tensor int8 and raw bounded i32. Uint8, nonzero zero points, narrowed output clamps and per-channel readouts are refused. Narrow signed input ranges are safe subsets of the proved full-byte domain, but a narrowed output range still requires an implemented clamp. Unbounded runtime i32 seeds, insufficient source guards, accumulator overflow, unproved bilinear gradients, float-extracted arithmetic maps, and any failed scale/affine transition proof are also refused. This is an implementation/proof limitation, not a claim that every refused operation is fundamentally impossible on Gemmini.

A scale's precision matters: the review's Python binary64 `.03 / (50 * .01)` is just below `3/50`, and the device candidate is refused. In source IR with binary32 `.03` and `.01`, their ratio is exactly 3; the exact result of sum 25 is 2, even when eager float produces 1. Tests and e2e receipts record that eager-float divergence without weakening equality.

## Reproduction

Use the model2MLIR environment with Torch/xDSL, this repository and selected Merlin/model2MLIR packages on `PYTHONPATH`. Select the supplied real RTL facts with `MERLIN_RTL_FACTS`. Device tests use the documented `GEMMINI_*` tool variables; no simulator or toolchain build is required. Caches use `UV_CACHE_DIR=/scratch/loren/.uv-cache`.

```sh
python -m pytest -q tests/core_aten merlin-support/tests/test_core_aten_execution.py tests/test_integer_contraction_patterns.py
python merlin-support/tools/sync_contracts.py --source "$MERLIN_SOURCE_ROOT/examples/gemmini/target/contracts" --check
python tests/core_aten/e2e/run_e2e.py tests/fixtures/core_aten --rtl --json out/exactness-e2e.json
python tests/core_aten/e2e/make_exact_cases.py out/exactness/captures
python tests/core_aten/e2e/run_e2e.py out/exactness/captures --rtl --batch adversarial --json out/exactness-adversarial.json
python tests/core_aten/e2e/run_offload.py out/exactness/captures --only mean_tie seeded_3_17_5 seeded_runtime
```

For support tests select `MERLIN_TARGET_PATH` to this checkout's `merlin-support`, and `MERLIN_CHIPYARD` to the supplied Chipyard installation. The support suite's optional experiment/conformance dependencies are separate from the core backend.

## Results

- Focused suite: **100 passed**, 2 conditional device tests skipped, and **95 capture subtests passed**. The two hardware engines were exercised separately below.
- Spike and Verilator: **26 direct device checks per engine**, including all 65,536 signed-byte add pairs, the mean tie, three constant-seeded tails, a guarded runtime seed at extreme values, and the odd ceil/divisor case. **Three whole-model C-interface checks per engine** also passed. All audited ELFs passed the no-FSM audit.
- The 41 original current-format captures split into **19 fully admitted** and **22 refused** graphs. Every admitted graph passed exact equality on both engines. Eager-float divergence is informational, including the mean-tie result.
- Broad repository run: **1,503 passed, 28 failed, 8 skipped**, 123 subtests passed (856.87 seconds). Reruns resolve four early seeded failures, the inventory/schema environment failure, and segmented input binding. **22 checks remain unavailable/failing:** 13 need absent historical Git objects (`eefe844`, `d1d0e80`, `4e1630b`); seven need a native clang compatible with the emitted newer LLVM IR; two unchanged whole-model identity-plan preservation checks fail. Those checks were not weakened.
- Support suite with its installed Merlin environment and explicit provider: **108 passed, 2 failed, 2 skipped**, excluding the recording module that cannot collect. Both CLI failures and the uncollectable recording module require the unavailable optional `aet` dependency. The contract sync/drift and provenance tests pass.
